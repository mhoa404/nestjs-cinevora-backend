Trước khi trả lời, hãy dùng thư mục `.ai/` làm bản đồ dự án.

Thứ tự làm việc bắt buộc:
1. Đọc `.ai/architecture-summary.md`
2. Đọc `.ai/repo-map.json`
3. Đọc `.ai/modules/movies.summary.md`
4. Đọc `.ai/tests-index.json` nếu có test liên quan
5. Nếu chưa đủ chắc chắn, yêu cầu đúng file source cần xem thêm

Nguyên tắc:
- Không đoán khi chưa có source code thật
- Phân biệt rõ summary với logic thật trong source

## Database Understanding
Khi câu hỏi liên quan database, entity, migration hoặc relation, phải đọc theo thứ tự:
1. `.ai/database-schema-current.md`
2. `.ai/entities-index.json`
3. file migration liên quan
4. entity liên quan

Không được coi ảnh ERD là nguồn sự thật tuyệt đối nếu migration/entity đang khác.
